# Portfolio: BI / DWH Modernization in Microsoft Fabric

As a specialist in **Business Intelligence and Data Warehousing**, this portfolio demonstrates the modernization of legacy analytics into **cloud-native Microsoft Fabric solutions**.  

It showcases the translation of traditional ETL logic into:

- Scalable **Dataflow Gen2 ingestion pipelines**
- Reusable **semantic models**
- Operational **Power BI dashboards**
- Automated **CI/CD deployment workflows**

---

# What I’ve Built

## Inventory Analytics Pipeline
- Modeled **dimension and fact tables** using Dataflow Gen2  
- Simulated missing operational metrics such as:
  - Cost of Goods Sold (COGS)
  - Physical Count
  - Order Shipped Date
  - Inventory Turnover
  - Unit Cost
  - Units Sold  
- Engineered dynamic analytical flags:
  - **Stockout**
  - **Reorder**
  - **Overstock**
- Built **semantic models and Power BI dashboards** with KPI cards, drillthrough, and performance indicators  

---

## Customer Churn Workflow
- Implemented **churn prediction logic** using Fabric Notebooks  
  - Python  
  - PySpark  
  - SQL  
- Generated **synthetic datasets** to accelerate development and testing  
- Designed **scalable logic reusable across business units**

---

## CI/CD and Version Control
- Git-based version control for:
  - Power Query (M)
  - DAX measures
  - Pipeline configurations  
- Automated **deployment validation and schema checks** via DevOps pipelines  

---

# Highlights

- **Dataflows** – Automated ingestion pipelines built with Power Query (M)  
- **Notebooks** – Python and Spark-based transformations executed in Fabric  
- **Semantic Models** – Tabular models, measures, and relationships optimized for analytics  
- **Dashboards** – Power BI reports with field parameters, KPIs, and scorecards  
- **CI/CD** – End-to-end deployment automation using YAML pipelines
